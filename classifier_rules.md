# 3D Library Organization Rules & Classifier

This script classifies loose files in `X:\3d files\3d files` into:
1. Category (`fantasy`, `sci fi`, `WWII`, `historical`, `cyberpunk`, `terrain`, `bases`, etc.)
2. Creator Studio (e.g. `Skull Forge Studios`, `OnePageRules`, `Last Sword Miniatures`, `Sacrusmundus`, `Mezgike`, `Sons of Ymir`)
3. Release / Pack (e.g. `2021-04`, `SQ107`, `Saurian Ancients`)
4. Contents (clean descriptive item name)

## Known Creator Codes and Signatures:
- **Skull Forge Studios**: Codes `SQ###` (Squads), `PD###` (Protocol Droids), `BR###` (Bounty / Rebels), `HU###`, `VT###`.
- **OnePageRules**: `Grimdark Future`, `Reptilian / Saurian Ancients`, `Alien Hives`, `Battle Brothers`.
- **Sacrusmundus**: `Sacrusmundus YY_MM [Name]` (e.g. 21_11 Krotone, 22-01 Tulipa).
- **Last Sword Miniatures**: Explicit studio tag or known lines (e.g. `Salamanders (Last Sword Miniatures)`).
- **Mezgike**: E.g. `by Mezgike`.
- **Sons of Ymir**: `Sons of Ymir`, `SoY Dwarf [Unit]`.
- **Raven Twin Miniatures**: `Raven Twin [Month Year]`.
- **RN Estudio**: `RN Estudio`, `RNEstudio`.
- **Red Makers / Red Pilgrim**: `red makers`, `Red Pilgrim`.
- **Dark Fire Designs**: `DarkFire`, `Dark Fire`.
- **Rocket Pig Games**: `Rocket Pig Games`.
- **Runic Collectibles**: `Runic Collectibles`.
- **Standard Bases**: `Round_XXmm_verX.stl`, `Round_lip_XXmm_verX.stl`.
